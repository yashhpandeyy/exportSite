# EverHorizon Exim — Company Website

Static site for EverHorizon Exim, a virgin paper / paper roll / premium A4 manufacturer & exporter based in Mahesana, Gujarat, India.

## Structure
- `index.html` — homepage (hero, about, products, export, why-us, contact)
- `privacy-policy.html` — privacy policy page
- `style.css` — shared design system (colors, type, components)
- `images/` — logo, mark, and product photography

## Run locally
Just open `index.html` in a browser — no build step required.
